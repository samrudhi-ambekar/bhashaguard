# BhashaGuard

**Detect. Fix. Preview.**

BhashaGuard is a Chrome extension prototype that uses Gemma 4
to identify potential localization defects and suggest Marathi
corrections for human review.

## Planned Features
- User-triggered webpage scanning
- Screenshot and visible-text analysis
- Evidence-backed localization findings
- Reviewable Marathi corrections
- Safe Apply and Undo
- Graphify codebase visualization

## Status
Under development for a hackathon.

AI analysis, correction workflows, and Graphify artifacts will be
marked complete only after they have been implemented and tested.
